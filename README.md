# AZAHAR HEAT

An original open-world crime game in the fictional sunset port city of Puerto Azahar, built for the make.fun "Make GTA 6" bounty (gta6-01). Playable in a desktop browser from static files, no network requests: explore the city on foot and by car, steal cars, run story missions, outrun the police and raise your wanted level.

- `main.ts` — the entry program (Node 22) that the kit runs.
- `vendor/makefun-game.ts` — kit plumbing, copied unchanged.
- `game/` — the playable game as static files (`game/index.html`).
- `screenshots/` — real renders of the game.
